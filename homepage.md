# Homepage

Your home page is built from **sections** — self-contained blocks of content you can add, remove,
reorder and configure. Nothing is fixed except the header and footer.

**Where to find it:** Theme Editor → template dropdown → **Home page**.

---

## Working with sections

### Add a section

Click **Add section** in the left sidebar, choose one from the list, and it is inserted at the
bottom. Drag it into place.

### Remove a section

Select it in the sidebar and click **Remove section**. If you might want it back, use the
**Hide section** eye icon instead — hidden sections keep their content.

### Reorder sections

Drag the section in the left sidebar. The preview updates as you drop it.

### Customize a section

Select it. Its settings appear in the right sidebar, usually grouped as **Content**, **Layout**
and **Section** (color scheme and padding).

### Add and remove blocks

Sections that hold repeating content — slides, columns, testimonials, logos, FAQ rows — use
**blocks**. Expand the section in the left sidebar to see them, then **Add block** or select and
**Remove block**. Blocks reorder by dragging, just like sections.

### Section settings that appear almost everywhere

| Setting | What it does |
| --- | --- |
| **Color scheme** | Which of your color schemes the section uses. This is how you alternate light and dark bands down the page. |
| **Top padding** / **Bottom padding** | 0–100px each. Space above and below the section's content. |
| **Content width** | Reading (narrow, comfortable line length), Narrow, Wide, or Full — where offered. |
| **Columns on desktop** / **Columns on mobile** | Grid density at each size. |
| **Mobile layout** | Grid, Carousel, Scroll or Stacked, depending on the section. Carousel lets shoppers swipe rather than scroll past a tall stack. |

## What ships on the home page

A new install has eight sections already set up as a starting point:

1. Slideshow
2. Featured collection
3. Multicolumn
4. Collections
5. Image with text
6. Testimonials
7. Featured blog
8. Newsletter

Replace the placeholder content with your own, or remove what you do not need.

## Available sections

Every section below can be added to the home page. Most can also be added to any other template.

### Slideshow

A full-width carousel of image slides with text and buttons over them.

| Setting | Notes |
| --- | --- |
| **Slideshow height** | Adapt (follows the first slide's image proportions), Small, Medium, Large. |
| **Make section full width** | On by default. |
| **Transition** | **Slide** lets shoppers swipe the track directly and works before scripts load. **Fade** stacks the slides. |
| **Play slides automatically** | Off by default. Needs more than one slide. Never starts for visitors who prefer reduced motion, and a pause button is always shown. |
| **Time on each slide** | 4–12 seconds. |
| **Show arrows** / **Show dots** | Navigation controls. |
| **Accessible label** | Announced by screen readers to distinguish this carousel from others on the page. |

**Slide blocks** (up to 8) each carry: desktop image, mobile image, subheading, heading, text, an
optional whole-slide link, two buttons with independent styles, content position (nine positions),
text alignment, overlay opacity and a color scheme for the text over the image.

**Images:** landscape, at least 2400px wide for a full-width slideshow. Add a **mobile image**
cropped to portrait — a wide hero cropped to a phone screen usually loses its subject. Set the
focal point in Shopify's image editor so the crop keeps what matters.

**Mobile:** slides fill the width; text sizes down automatically. Two or three slides is plenty —
most shoppers never see slide four.

---

### Image banner

A single full-width image with text and up to two buttons over it. Simpler than a slideshow, and
usually a better choice.

| Setting | Notes |
| --- | --- |
| **Image** / **Mobile image** | The mobile image is used below 750px. Leave it empty to use the same image everywhere. |
| **Banner height** | Adapt, Small, Medium, Large. |
| **Content position** | Nine positions across the banner. |
| **Overlay opacity** | 0–90%. Darkens the image so text stays readable. Raise it for busy photography. |
| **Overlay color scheme** | Sets the text color over the image and the tint of the overlay. Pick a dark-background scheme for light text. |
| **Two buttons** | Each with its own label, link and Primary/Secondary style. |

**Recommended:** one image banner near the top of the page, with a single clear call to action.
Two competing buttons dilute it.

### Featured collection

A row or grid of products from one collection.

| Setting | Notes |
| --- | --- |
| **Collection** | Which collection to show. |
| **Heading** | Leave blank to use the collection's own title. |
| **Products to show** | 2–16. |
| **Show a link to the collection** | A "View all" link. On by default. |
| **Columns on desktop** | 2–5. |
| **Columns on mobile** | 1 or 2. |
| **Mobile layout** | Grid or Scroll. |
| **Image ratio** | Adapt, Square, Portrait, Landscape. |
| **Show vendor**, **Show product rating**, **Quick add** | Override the global product card settings for this section only. |

**Recommended:** four columns, eight products — two clean rows on desktop. See
[Product cards](product-cards.md).

### Featured product

One product presented at full width, with its image beside a summary and a link to the full
product page.

| Setting | Notes |
| --- | --- |
| **Product** | Which product. |
| **Button label** | Leave blank for "View details". |
| **Show vendor**, **Show product rating**, **Show description**, **Show sold out and sale badges** | Content toggles. |
| **Show description** | Shows the first 45 words of the description, with formatting removed. |
| **Image position** | Left or right. |
| **Image ratio**, **Content alignment** | Layout. |

Useful for a hero product or a new launch. It links to the product page rather than adding to
cart, so shoppers still see full variant and stock information before buying.

### Collections

A grid of collection cards.

| Setting | Notes |
| --- | --- |
| **Collections** | Pick the collections to show, in order. |
| **Heading**, **Description**, **Text alignment** | Section header. |
| **Columns on desktop** | 2–5. **Columns on mobile**: 1 or 2. |
| **Mobile layout** | Grid or Scroll. |
| **Image ratio** | Square, Portrait, Landscape, Wide. |
| **Card style** | **Stacked** puts the title below the image. **Overlay** puts it over the image. |
| **Show product count** | Shows how many products are in each collection. |
| **Show a link to all collections** | Links to the collections list page. |

Each card uses the **collection image** set in Shopify admin. Collections without one fall back
to a placeholder — set collection images before using this section.

### Image with text

An image beside a block of text with a button. The standard "tell your story" section.

| Setting | Notes |
| --- | --- |
| **Image** | One image. |
| **Subheading**, **Heading**, **Text**, **Button** | Content. |
| **Image position on desktop** | Left or right. |
| **Order on mobile** | Image first or content first. |
| **Column proportions** | Equal, Wide media, or Wide content. |
| **Image ratio** | Adapt, Square, Portrait, Landscape, Wide. |

**Recommended:** alternate the image position if you use two of these in a row, and keep the text
to about 40 words.

### Multicolumn

Two to six columns, each with an icon or image, a heading, text and an optional link. The usual
home for trust signals — delivery, returns, guarantees.

| Setting | Notes |
| --- | --- |
| **Subheading**, **Heading**, and a section-level link | Header. |
| **Columns on desktop** | 2–6. **Mobile layout**: Grid or Carousel. **Columns on mobile**: 1 or 2. |
| **Image ratio** | Adapt, Square, Portrait, Landscape, Circle. |
| **Card style** | Plain or Card. |

**Column blocks** (up to 12): image *or* icon (an image replaces the icon), heading, text, and an
optional link. Icons available: Truck, Star, Success, Info, Pin, Mail, Phone.

**Recommended:** three columns. Only claim things you actually do.

### Collapsible content

An FAQ or details accordion, optionally beside an image.

| Setting | Notes |
| --- | --- |
| **Subheading**, **Heading** | Header. |
| **Open the first row by default** | Off by default. |
| **Let several rows stay open** | When off, opening a row closes the one already open. |
| **Image** | Adding one places the rows beside it on desktop and switches the section to full page width. |
| **Image position**, **Image ratio** | Only shown when an image is set. |
| **Content width** | Only shown when no image is set. |

**Row blocks** (up to 16): heading, rich text content, an optional **Page**, and an icon. The
page's content is appended below the text — so you can reuse a policy page you already maintain
rather than duplicating it. A row with neither text nor page stays hidden.

### Testimonials

Customer quotes with optional ratings and author photos.

| Setting | Notes |
| --- | --- |
| **Subheading**, **Heading** | Header. |
| **Show rating** | Shows the star rating on each testimonial. |
| **Columns on desktop** | 2–4. **Mobile layout**: Grid or Carousel. |
| **Card style** | Plain or Card. **Author photo shape**: Circle or Square. |

**Testimonial blocks** (up to 12): quote, rating out of 5, author, author role, author photo.

These are quotes you type in, not live reviews. Use real customer feedback with permission. If
you want verified reviews tied to products, install a review app — see
[Third-party apps](third-party-apps.md).

### Logo list

A row or scrolling marquee of brand or press logos.

| Setting | Notes |
| --- | --- |
| **Heading** | Optional. |
| **Layout** | **Grid** or **Marquee** (continuous horizontal scroll). |
| **Columns on desktop** (3–8) / **Columns on mobile** (2–4) | Grid layout only. |
| **Time for one loop** (15–90s), **Scroll direction**, **Pause when hovered** | Marquee layout only. |
| **Logo height** | 24–96px. |
| **Fade logos to gray** | Logos return to full color on hover or keyboard focus. |

**Logo blocks** (up to 16): image, brand name (used as alt text when the image has none), and an
optional link.

**Images:** supply logos as transparent PNG or SVG, all at a similar visual weight, or the row
will look uneven.

### Marquee

A continuously scrolling line of short text items with icons. A lightweight way to run trust
signals or a sale message across the page.

| Setting | Notes |
| --- | --- |
| **Time for one loop** | 10–90 seconds. Higher scrolls more slowly. |
| **Scroll direction**, **Pause when hovered** | Behavior. |
| **Text size** | Small, Medium, Large. **Space between items**: 16–96px. |
| **Make section full width** | On by default. |

**Text blocks** (up to 12): text plus an icon.

Visitors who prefer reduced motion see the text standing still rather than scrolling.

| Setting | Notes |
| --- | --- |
| **Blog** | Which blog. |
| **Subheading**, **Heading**, **Heading size** | Header. |
| **Posts to show** | 2–8. **Columns on desktop**: 2–4. |

### Video

One video, either as a cover image that plays on click, or as a muted background.

| Setting | Notes |
| --- | --- |
| **Video** | A Shopify-hosted video. Takes priority over the URL below, and is the only option that can play as a background. |
| **YouTube or Vimeo URL** | Used only when no Shopify-hosted video is set. The player and its third-party scripts load only after a visitor presses play. |
| **Cover image** | Shown before playback. Shopify-hosted videos fall back to their own preview frame. |
| **Description** | Describes the video for screen readers and is used as the cover image's alt text. Falls back to the heading. |
| **Subheading**, **Heading** | Content above the video. |
| **Presentation** | **Cover image** (click to play) or **Background** (muted, looping, no controls). Background needs a Shopify-hosted video and stays paused for visitors who prefer reduced motion. |
| **Aspect ratio** | 16:9, 4:3, 1:1, 21:9. |
| **Make section full width** | Off by default. |

**Recommended:** self-host short videos with Shopify. A YouTube embed is fine for longer content
— the theme already defers loading it until play is pressed, so it costs nothing until used.

### Before and after

A draggable slider comparing two images.

| Setting | Notes |
| --- | --- |
| **Before image** / **After image** | Use two images with the **same dimensions** so the halves line up. |
| **Before label** / **After label** | Text overlays. |
| **Starting position** | 0–100%. Where the divider sits when the page loads. |
| **Image ratio** | Adapt, Square, Portrait, Landscape, Wide. |
| **Heading**, **Text** | Optional content above. |

Useful for skincare, cleaning, restoration, home improvement and anything with a visible result.
Both images must be genuinely the same subject, same framing and same lighting, or it reads as a
trick.

### Countdown

A timer counting down to a specific date and time.

| Setting | Notes |
| --- | --- |
| **End date** | Format `YYYY-MM-DD`, for example `2026-12-24`. Leave blank to hide the section. |
| **End time** | 24-hour format, for example `23:59`. Uses your store's time zone. |
| **Heading**, **Text**, **Button** | Content. |
| **Message when the countdown ends** | Replaces the timer once the date passes. Leave blank to hide the section instead. |
| **Content alignment** | Left, center or right. |

**This timer is honest by design.** It counts down to one fixed moment for every visitor. It does
not restart, it does not run a per-visitor clock, and there is no "evergreen" mode. When the date
passes it shows your ending message or removes itself.

If you use it, run a real deadline and honour it.

### Newsletter

An email sign-up form. Sign-ups are saved as customers in your admin, tagged `newsletter`.

| Setting | Notes |
| --- | --- |
| **Subheading**, **Heading**, **Text** | Content. |
| **Button label** | Leave blank for "Subscribe". |
| **Ask for a first name** | Adds a name field. Off by default. |
| **Disclaimer** | Shown under the form, for a privacy note or consent wording. Disappears once someone has subscribed. |
| **Background image** | Adding one turns the section into a banner and enables the overlay and height settings. |
| **Overlay opacity**, **Height** | Background image only. |
| **Make section full width**, **Content alignment** | Layout. |

The theme collects the sign-up. Sending the emails is your email platform's job — connect one
from the Shopify App Store, or use Shopify Email.

### Custom section

| Setting | Notes |
| --- | --- |
| **Background image**, **Overlay opacity** | Optional background. |
| **Content width** | Reading, Narrow, Wide, Full. |

Reach for this when no other section fits, before reaching for custom code.

## Building a good home page

A workable order for most stores:

1. **Slideshow** or **Image banner** — one clear message and one call to action
2. **Featured collection** — your best or newest products, immediately shoppable
3. **Collections** — routes into the rest of the catalog
4. **Image with text** — who you are, briefly
5. **Multicolumn** — delivery, returns, guarantee
6. **Testimonials** — proof
7. **Newsletter** — the ask

Guidelines:

- **Six to eight sections.** Shoppers rarely scroll past that.
- **Alternate color schemes** between adjacent sections so the page has rhythm.
- **One primary call to action** in the first screen.
- **Preview on a phone** as you build, not after. Over half your visitors are likely on one.
- **Remove what you cannot fill.** An empty section is worse than a missing one.
